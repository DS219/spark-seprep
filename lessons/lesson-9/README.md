# Lesson 9: Build Something People Use

Week 1 of a four-class portfolio project. Covers what employers look for now
that everyone has AI coding tools: planning, design, directing a coding agent,
and verifying its work. Students write a scope sentence, plan with OpenCode,
build the smallest working version, and get their first user feedback from a
partner. Class 4 is 2-minute presentations.
Uses the same Slidev tooling and shared visual system as the other course lessons.

## Present

Requires Node.js 20.12 or newer.

```bash
cd lessons/lesson-9
npm ci
npm run dev
```

Press `P` for presenter mode. Build or export for offline use:

```bash
npm run build
npm run export
```

## Before class

- **Bring two or three real job postings** for junior or new-grad roles that
  mention AI tools, coding assistants, or LLMs. Slides 4 to 8 quote them; replace them each term.
- Check that **Settings → General → Show agent** shows the Plan/Build picker in
  your OpenCode Desktop version. The class works without it.
- Decide the submission location and the Week 1 checkpoint points.
- Remind students to bring laptops with OpenCode Desktop working. llmman is optional.
