## Refresh guidance

Before teaching this lesson in a later semester:

- recheck foundation relationships and project counts;
- refresh CNCF survey figures or remove them if a newer report is unavailable;
- update newly hosted PyTorch Foundation projects if examples change;
- verify the OpenClaw Foundation description and nonprofit status;
- verify the course repository's current license and activity; and
- avoid hard-coding ecosystem counts unless the number supports a specific teaching point.
