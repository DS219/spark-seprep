## SSH and keys

- [Google Cloud: Connect to Linux VMs](https://docs.cloud.google.com/compute/docs/connect/standard-ssh)
- [Google Cloud: Best practices for protecting SSH credentials](https://docs.cloud.google.com/compute/docs/connect/ssh-best-practices/credentials)
- [GitHub: Generate a new SSH key and add it to the ssh-agent](https://docs.github.com/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent)

## Refresh triggers

- Recheck platform setup instructions before each semester.
- Recheck GitHub's recommended key algorithms before changing key-generation commands.
- Verify the class VM's address, username convention, host-key fingerprint, temporary-password flow, and SSH configuration before class.
- Test all student commands against a non-root account on the actual class VM.
