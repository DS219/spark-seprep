## Example Code
```
def ticket(speeds):
	for i in speeds:
		if i > 65:
			return "You have been given a speeding ticket"
	return "You are under the speeding limit"
```

### Code Explanation
tickets takes in a list of recorded speeds and checks if the driver is going above or below the speed limit. If any of their speeds are above the speed limit, they will be awarded a speeding ticket, and if not, the function will return "You are under the speeding limit".
