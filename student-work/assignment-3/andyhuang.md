## Example code

```python
# List of test scores
scores = [85, 92, 78, 90, 88]

total = sum(scores)
average = total / len(scores)

print(f"Scores: {scores}")
print(f"Average score: {average}")
```

### Code Explanation

This code stores a list of test scores. By using `sum()`, it adds up the scores, then divides by how many scores there are with `len()` to get the average. To run it, copy and paste the code in any software that enables Python language.
