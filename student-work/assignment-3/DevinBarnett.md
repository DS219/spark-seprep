# Devin Barnett

Hi, my name is Devin and my favorite programing language is Ruby because its core design philosophy is focuses on programmer happiness and productivity!

## Example code

```
name = "Devin"
age = 21

# Using puts to print text with a trailing newline
puts "Hello, my name is #{name} and I am #{age} years old."

# String methods
puts name.upcase      # Outputs: Devin
puts name.length      # Outputs: 5
```

### Code explanation

This script will display the user's details and string modifications each time you run it. To run from the terminal, copy the above to a `profile.rb` and run it with `ruby profile.rb`.
You need to have Ruby installed. See [Ruby install documentation.](https://www.ruby-lang.org/en/documentation/installation/).
