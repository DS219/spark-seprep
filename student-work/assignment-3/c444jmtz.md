## Example code

### Code Explanation

This Rust program prints “Hello, world!” to the console. To run it:

1. Install Rust using `rustup` (the official installer).
2. Create a new project with `cargo new hello_world`.
3. Replace the contents of `src/main.rs` with code
4. Run the program using `cargo run`.
