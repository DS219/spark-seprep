## Example code

```python
scores = [85, 90, 95]
average = sum(scores) / len(scores)
print(f"The average score is {average:.1f}")
```

### Code Explanation

This code calculates the average of three scores. The sum() function adds the scores, and len() counts how many scores there are. Dividing the total by the count gives the average. The result is printed with one decimal place.

To run this example, save the code in a file named average.py. With Python 3 installed, run `python3 average.py` in the terminal. The expected output is `The average score is 90.0`.
