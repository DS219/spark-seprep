## Example code

```python
import random

jokes = [
    "Why do programmers prefer dark mode? Because light attracts bugs.",
    "There are 10 types of people in the world: those who understand binary and those who don't.",
    "Why did the programmer quit his job? Because he didn't get arrays.",
    "My sea sickness comes in waves.",
]

print(random.choice(jokes))
```

### Code explanation

This script keeps a list of jokes and prints one at random each time you run it. `random.choice` picks a single item from the list.

To run it, save the code above to a file called `jokes.py` and run it from the terminal with `python3 jokes.py`. You need Python 3 installed, which comes with macOS and most Linux systems.
